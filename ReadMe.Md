**Inventory Backend-API Project**

This project contains a back-end API for inventory management. It is a simple API created by Brandon Richards as an independent software engineering practice project. Its purpose was to prove the student could write a simple API that could be called from a separate application.

**Inventory Management Project**

This project contains a second project that allows a user to create inventory products using the API backend previously mentioned. This project uses a blazor default UI for simplicity. Its purpose was to enable the student to practice using his own API's in a separate application.

**PokeAPI**

The inventory management project also includes a pokemon API call. The purpose of this was to give the student practice building an external API call. The student used PokeAPI documentation and RESTFUL http calls to test and translate data into my app for use.
